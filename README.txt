TERANGA — Code source du site

Version du 6 octobre 2026, avec les fiches du personnel.

OUVRIR LE SITE
Décompressez le ZIP, puis ouvrez index.html dans votre navigateur.
Pour utiliser un serveur local :
  python -m http.server 8000
Puis ouvrez http://localhost:8000

MODIFIER LE SITE
Le HTML, les styles CSS et le JavaScript du site sont dans index.html.
Les images et les bibliothèques GSAP sont dans le même dossier.
Aucune installation npm et aucune compilation ne sont nécessaires.
Les polices Google nécessitent une connexion Internet ; des polices de secours sont prévues.

CONTENU
- index.html : structure, styles et interactions
- orchard.webp : photographie du verger
- person-0.webp à person-4.webp : portraits d’illustration générés
- gsap.min.js et ScrollTrigger.min.js : animation

Le formulaire prépare un récapitulatif à copier ; il ne transmet pas de message.
Les noms, rôles et portraits du personnel sont ceux du concept de présentation.
Remplacez-les par les informations et photos validées avant une utilisation commerciale.
